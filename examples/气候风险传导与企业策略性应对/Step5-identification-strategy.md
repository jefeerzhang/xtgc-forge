# Step 5 · 因果识别策略

> 基于选定主题与研究类型(推断性才启用)。

## 研究类型判断
推断性 / / 描述性 / / 质性: 推断性

## 推断性策略
本研究属于推断性实证研究，需要在面板模型基础上解决气候风险的潜在内生性（反向因果与遗漏变量）。主要识别策略为**双向固定效应面板 + 工具变量法 + 双重机器学习 (DML)**，并辅以面板门槛回归捕捉 H3 的非线性效应。

### 模型
- 主回归模型：双向固定效应 (Firm FE + Year FE)
- 内生性应对：工具变量法 (IV) + 双重机器学习 (DML) 部分线性回归
- 非线性识别：Hansen 面板门槛回归
- 政策情景分析：交错 DID (Staggered DID)

### 变量度量
- IV（自变量）:
  - `PRisk_it`: 物理气候风险指数（基于中国 456 个气象站点逐日数据测算的县域层面极端高温/洪涝/干旱频次与强度，加权聚合到企业所在地级市）
  - `TRisk_it`: 转型气候风险指数（基于企业年报 + 政策文本中"碳市场""碳关税""能耗双控"等关键词频次，采用 TF-IDF 与 BERT-wwm 联合测算）
  - `PRisk_it/TRisk_it`: 双重风险比值（用于 H3 门槛识别）
- DV（因变量）:
  - `TaxAvoid_it`: 避税程度（账税差异 BDD 与会税差异 DTAX 双重测算）
  - `GreenRD_it`: 实质性绿色研发（绿色专利申请数 + 研发支出中环保占比）
  - `GreenCapEx_it`: 实质性绿色资本支出（环保投资 / 总资本支出）
- 中介:
  - `CashFlowStress_it`: 现金流断裂压力指数（基于经营性现金流 / 短期债务）
  - `FinConstraint_it`: 融资约束（SA 指数）

### 工具变量(IV)候选
- **IV1（针对 PRisk）**: 企业所在城市历史 50 年（1970-2019）极端气候频次均值
  - 理由: 历史气候特征满足相关性（与当前 PRisk 正相关）与排他性（与当前企业财务决策无直接影响）
- **IV2（针对 PRisk）**: 同行业其他企业（剔除本企业）的平均物理风险敞口
  - 理由: 行业层面气候冲击的外生性更强
- **IV3（针对 TRisk）**: 全国碳市场试点城市虚拟变量与地方人大环境立法频次的交互项
  - 理由: 政策推进的"地理扩散"提供准自然实验

### 稳健性检验清单
- [x] 替换 IV 度量（PRisk 替换为标准化降水指数 SPI / TRisk 替换为 SAWS 评分）
- [x] 缩短样本期（剔除 2020 年疫情扰动）
- [x] 子样本分组（国企 vs 非国企；高碳 vs 低碳行业；东中西部）
- [x] Placebo（伪政策时间与伪处理组）
- [x] 共同方法偏差（Harman's 单因子检验）
- [x] 替换 DV 度量（BDD 替换为 DTAX / Effective Tax Rate）

### 反例与威胁
- 威胁 1: 气候风险与企业财务决策同时受到宏观经济周期影响，可能存在时间趋势遗漏
  - 对策: 控制 Year FE 与 GDP 增速、宏观不确定性指数
- 威胁 2: 物理风险与转型风险高度相关，可能存在多重共线性
  - 对策: VIF 检测 + 残差化（orthogonalization）方法将二者剥离
- 威胁 3: 文本分析法测算转型风险可能存在 BERT 词嵌入的语境漂移
  - 对策: 跨年滚动重训 + 关键词人工核验样本
