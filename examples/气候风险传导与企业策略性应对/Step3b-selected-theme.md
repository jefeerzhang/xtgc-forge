## 选定主题
**主题标题:** 气候物理与转型双重冲击下企业策略性行为分化：实质性转型还是隐蔽性避税？

### 研究问题(RQ)
```
主问题: 气候物理风险（急性外生冲击）与转型政策风险（持续性预期变化）下，企业的实质性创新资本支出与隐蔽性避税行为如何呈现非对称动态博弈？

子问题 1: 物理风险加剧时，企业是否显著提高避税程度以补充内部现金流？异质性体现在哪类企业？
子问题 2: 转型政策风险加剧时，企业是否显著提高实质性绿色研发与资本支出？
子问题 3: 双重风险同时存在时，两类策略行为是替代关系还是互补关系？临界点在哪？
```

### 理论贡献
1. **跨理论融合**：将会计实质性披露理论（自愿性规避型）与预防性储蓄理论（资本挤出型）进行有机融合，揭示气候风险诱发企业“何时从扭曲应对走向实质转型”的决策边界与临界条件。
2. **风险二元细分**：将气候风险进一步解构为物理（acute）与转型（chronic）二维异质性源头，弥补现有文献把气候风险作为单一指数的扁平化处理。
3. **策略行为映射**：构建"实质性转型—隐蔽性避税"连续谱系理论模型，超越传统合规/违规二元对立视角。

### 研究类型标签
推断性 / / 描述性 / / 质性: 推断性

### 预期效应方向
- 物理风险 → 避税程度显著上升（α>0）预期 +
- 转型风险 → 实质性资本支出显著上升（β>0）预期 +
- 双重风险交互 → 异质性临界点（δ ≠ 0）预期 +
