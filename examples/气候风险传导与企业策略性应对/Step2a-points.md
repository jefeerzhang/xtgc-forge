# Step 2a · 文献要点卡

## 文献 L1
- **作者 / 年份**: Matsumura, Prakash, Vera-Muñoz (2023)
- **研究问题**: 管理层对气候风险实质性（materiality）的自愿披露行为如何影响企业整体风险？
- **理论框架**: 自愿披露理论、实质性原则与资本市场定价模型
- **数据 / 样本**: 美股上市公司 10-K 披露文本与市场风险数据
- **方法**: 文本分析测算气候实质性指标 + 面板回归 + Heckman 两阶段选择模型
- **主要发现**: 披露实质性气候风险能显著降低股价崩盘风险与资本成本，但若仅为象征性披露则无法产生避险溢价。
- **自报局限**: 未深入区分物理风险与转型政策风险的异质定价机制。
- **关联初判**: 提供微观企业实质性 vs 象征性应对的核心理论支撑。

## 文献 L2
- **作者 / 年份**: Ozkan, Temiz, Yildiz (2023)
- **研究问题**: 气候风险如何影响企业绩效？企业社会责任（CSR）在其中发挥何种调节机制？
- **理论框架**: 利益相关者理论、风险缓冲理论
- **数据 / 样本**: 跨国上市企业面板数据
- **方法**: 调节效应模型、高维固定效应
- **主要发现**: 气候风险显著削弱企业经营绩效，但高 CSR 投资能发挥“保险式缓冲”效应，平滑外生气候冲击。
- **自报局限**: 跨国样本缺乏宏观信贷政策环境的微观制度穿透。
- **关联初判**: 为企业策略性防御（CSR 作为缓冲垫）提供机制假说依据。

## 文献 L3
- **作者 / 年份**: 陶然 (2023)
- **研究问题**: 气候物理与转型风险是否会倒逼企业采取激进避税策略以补充内部现金流？
- **理论框架**: 预防性储蓄动机、委托代理理论
- **数据 / 样本**: 2007—2021 年中国 A 股上市公司
- **方法**: 账税差异（BDD）测算 + 双向固定效应 + IV
- **主要发现**: 随着气候风险上升，企业避税程度显著加深；融资约束是关键中介渠道，且在非国有和低透明度企业更显著。
- **自报局限**: 仅考虑了避税单项防御手段，未与企业资本结构重组做联合考察。
- **关联初判**: 证明气候风险会诱发微观企业的“隐蔽性/扭曲性策略应对”。

## 文献 L4
- **作者 / 年份**: 杜剑, 滕丹妮, 杨杨 (2023)
- **研究问题**: 机构投资者持股能否推动制造业重污染企业加强气候转型风险信息披露？
- **理论框架**: 公司治理理论、外部监督假说
- **数据 / 样本**: 2007—2020 年沪深制造业重污染上市企业
- **方法**: WinGo 财经文本挖掘 + 门槛回归
- **主要发现**: 机构投资者持股能显著提升披露水平，但在高审计质量企业中存在替代效应；披露能进一步倒逼绿色创新。
- **自报局限**: 仅局限于制造业重污染行业。
- **关联初判**: 揭示外部治理机制对企业气候透明度的重塑作用。

## 文献 L5
- **作者 / 年份**: 崔婕, 蔡源 (2023)
- **研究问题**: 气候风险事件如何通过网络关联在上市金融机构之间诱发系统性风险传染？
- **理论框架**: 复杂金融网络理论、系统性风险传染模型
- **数据 / 样本**: 2011—2021 年中国 51 家上市金融机构微观数据
- **方法**: TENET 尾部风险关联网络 + 空间溢出检验
- **主要发现**: 极端气候事件加剧了金融机构间的尾部关联度，银行与非银机构形成风险传染放大回路。
- **自报局限**: 未穿透到借款企业端的微观违约异质性。
- **关联初判**: 提供了气候风险从中观企业向宏观金融系统放大的传导链条。

## 文献 L6
- **作者 / 年份**: 夏晖, 陈曦, 闻月 (2023)
- **研究问题**: 转型气候风险在不同政策强度下对能源企业碳排放效率产生何种非线性冲击？
- **理论框架**: 波特假说、政策不确定性理论
- **数据 / 样本**: 2015—2021 年中国能源行业 A 股上市公司
- **方法**: 超效率 SBM 模型 + 文本分析
- **主要发现**: 转型初期风险增加会暂时压制碳效率，但研发创新投入能在中长期扭转该负向效应。
- **自报局限**: 行业样本集中于能源行业。
- **关联初判**: 为企业策略应对从“短期扭曲”走向“长期实质转型”提供动态时间窗口依据。
