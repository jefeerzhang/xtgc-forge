# Step 4 · 研究假设

> ✅ 基于真实 OCR 内容 + 选定主题"气候风险 → 企业绿色转型"。

---

## 核心命题**:**气候风险通过"经营风险"和"融资约束"两条路径抑制企业绿色转型**

---

## 假设 H1(主效应 · 强假设)

**假设陈述**:**气候风险显著抑制中国 A 股上市公司的绿色转型程度。**

### DAG 图(文字描述)

```
气候风险(X:物理 + 转型)
       │
       ├── → 经营风险 ↑(M1) →→ 绿色转型 ↓(Y)
       │                              ↑
       │                              │
       └── → 融资约束 ↑(M2) ──────────┘

控制变量(Z):企业规模、年龄、杠杆、行业、所有制、年份
```

### 反事实表述

> "如果同一家企业**没有气候风险敞口**(如 2007 年),其绿色转型程度会更高;**实际有气候风险**后,因经营风险上升 + 融资约束加剧,绿色转型程度下降。"

### 可证伪条件

- 气候风险与绿色转型不显著 → 拒绝 H1
- 物理 vs 转型风险方向不一致 → 部分拒绝

### 最小效应量(SESOI)

- **绿色转型程度**:基于 L5 的度量方法(7 维度 + BP 神经网络),SESOI = 绿色转型综合得分下降 ≥ 5%
- 或参考 L4 的 GTFP 度量,SESOI = GTFP 下降 ≥ 3%

### 检验策略

- **主检验**:双向固定效应回归,气候风险(IV)→ 绿色转型(DV)
- **机制检验**:Bootstrap 中介(Baron-Kenny + Hayes PROCESS)
- **稳健性**:替换气候风险度量 / 替换绿色转型度量 / 缩短样本期

---

## 假设 H2(中介:经营风险 · 强假设)

**假设陈述**:**气候风险通过提高企业经营风险,进而抑制绿色转型。**

### DAG 描述

```
气候风险 → 经营风险(收益波动率、Z-score) → 绿色转型 ↓
```

### 反事实

> "气候风险提升后,企业经营不确定性增加,管理层倾向于减少长期投资(包括绿色转型这类长周期投资)。"

### 可证伪

- 中介不显著 → 拒绝 H2

### SESOI

- 经营风险变化:σ(收益) ≥ +5%

### 检验策略

- 经营风险度量:3 年滚动 σ(ROA)+ Z-score(破产风险)
- Bootstrap 中介

---

## 假设 H3(中介:融资约束 · 强假设)

**假设陈述**:**气候风险通过加剧企业融资约束,进而抑制绿色转型。**

### DAG 描述

```
气候风险 → 融资约束(SA 指数) → 绿色转型 ↓
```

### 反事实

> "气候风险提升后,债权人风险厌恶上升,企业融资成本上升,资金被占用,绿色转型投资被挤出。"

### 可证伪

- 中介不显著 → 拒绝 H3

### SESOI

- SA 指数变化 ≥ +0.05

### 检验策略

- 融资约束度量:SA 指数 / KZ 指数
- Bootstrap 中介

---

## 假设 H4(异质性:行业 · 边界条件)

**假设陈述**:**气候风险对绿色转型的抑制效应在重污染行业更显著(因碳排放更多暴露于政策)。**

### DAG 描述

```
气候风险 → 绿色转型 ↓
       │
       └─ 行业类型(W:重污染 vs 轻污染) → 调节
```

### 反事实

> "同等气候风险下,重污染企业的绿色转型下降幅度是轻污染的 2-3 倍。"

### 可证伪

- 行业交互项不显著 → 拒绝 H4

### SESOI

- 重污染 vs 轻污染效应差 ≥ 1.5 倍

### 检验策略

- 行业分组 + 交互项 DID

---

## 假设 H5(异质性:所有制 · 边界条件)

**假设陈述**:**气候风险对绿色转型的抑制效应在非国有企业更显著(因民企融资约束更严重)。**

### DAG 描述

```
气候风险 → 绿色转型 ↓
       │
       └─ 所有制(W:国有 vs 非国有) → 调节
```

### 反事实

> "同等气候风险下,非国有企业的绿色转型下降幅度比国有大 50%。"

### 可证伪

- 所有制交互项不显著 → 拒绝 H5
- 与假设 H4 的方向相互验证

### SESOI

- 非国有 vs 国有效应差 ≥ 30%

### 检验策略

- 所有制分组 + 交互项

---

## 假设体系总结

| 假设 | 强度 | 类型 | 检验方法 |
|---|---|---|---|
| H1 气候风险抑制绿色转型 | 强 | 主效应 | 固定效应回归 |
| H2 经营风险中介 | 强 | 中介 | Bootstrap |
| H3 融资约束中介 | 强 | 中介 | Bootstrap |
| H4 行业异质性 | 中 | 边界 | 交互 DID |
| H5 所有制异质性 | 中 | 边界 | 交互 DID |
