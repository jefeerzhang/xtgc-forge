## 🎯 跑通结果

### 核心 Gap(填补)

1. **GAP-B1**:气候风险对微观企业绿色转型的影响(空白,高价值)
2. **GAP-B3**:数字化作为气候风险的调节器(空白,高价值)

### 选定主题
**气候风险对企业绿色转型的影响 — 基于 A 股上市公司的实证**

### 5 个研究假设
- **H1**(主效应):气候风险抑制绿色转型
- **H2**(中介):经营风险路径
- **H3**(中介):融资约束路径
- **H4**(边界):行业异质性
- **H5**(边界):所有制异质性

### 方法
双向固定效应 + IV(气温异常 / 碳交易试点)+ Bootstrap 中介
