## 模糊领域

```
气候风险是否以及如何影响中国企业（尤其是 A 股上市公司）的绿色转型？
物理风险与转型风险是否有差异？融资约束 / 经营风险是否构成中介？
数字化转型能否缓冲气候风险对绿色转型的抑制？
```
