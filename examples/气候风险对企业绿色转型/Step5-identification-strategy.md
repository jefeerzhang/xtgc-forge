## 推断性策略

### 总思路:**双重固定效应 + 工具变量 + 中介效应 + 异质性**

### H1 主效应识别

| 维度 | 方法 |
|---|---|
| 模型 | 双向固定效应(企业 + 年份)+ 聚类标准误(企业层) |
| 气候风险度量 | 文本挖掘(年报"气候/环境/碳"词频 × log(词频+1)) |
| 绿色转型度量 | 参考 L5:7 维度(文化/战略/创新/投入/生产/排放)+ BP 神经网络赋权 |
| 工具变量(IV) | **省级年度气温异常值**(物理风险 IV)+ **省级碳排放权交易试点**(转型风险 IV,2013/2017) |
| 内生性来源 | 气候风险与企业绿色转型同时受"环保意识"等遗漏变量驱动;反向因果(绿色转型也降低风险) |
| 平行趋势 | 政策 DID 需 placebo + 缩短样本期检验 |

### H2 / H3 中介识别

| 中介 | 度量 | 检验 |
|---|---|---|
| 经营风险(H2)| 3 年滚动 σ(ROA)、Z-score | Bootstrap(Baron-Kenny + Hayes PROCESS Model 4)|
| 融资约束(H3)| SA 指数、KZ 指数 | Bootstrap |

### H4 / H5 异质性识别

| 维度 | 分组 | 方法 |
|---|---|---|
| H4 行业 | 重污染 vs 轻污染(参考环保部 2010 名单) | 交互项 + 分组回归 |
| H5 所有制 | 国有 vs 非国有 | 交互项 + 分组回归 |

### 工具变量(IV)候选

- **IV1**:省级年度气温异常值(高温/低温日数)作为物理风险的 IV
- **IV2**:碳排放权交易试点(2013 深圳、2017 扩展)作为转型风险的政策 IV
- **IV3**:省级"环保法实施强度"作为政策冲击 IV

### 稳健性检验清单

- [ ] **替换气候风险度量**:用 CSMAR 气候风险评分 / L2 的方法重新度量
- [ ] **替换绿色转型度量**:用 GTFP(参考 L4)+ 绿色专利(参考 L5)替换
- [ ] **缩短样本期**:排除 2020(疫情)+ 排除 2008-2009(危机)
- [ ] **子样本**:重污染 vs 轻污染、国有 vs 非国有、大企业 vs 中小企业
- [ ] **替代 IV**:换 2-3 个 IV 看效应是否稳健
- [ ] **Placebo**:对未实施政策的"伪处理组"做伪 DID
- [ ] **共同方法偏差**:Harman's 单因子检验 + 控制词频总词数

### 反例与威胁

- **威胁 1**:文本识别误差(气候风险词频误识别)→ 用多重指标 + 人工抽检
- **威胁 2**:反向因果(绿色转型降低风险)→ 用滞后变量 + IV 应对
- **威胁 3**:遗漏变量(管理层能力 / ESG 评级)→ 用固定效应 + 控制变量
- **威胁 4**:样本选择偏差(只存活企业)→ 用 Heckman 两阶段
