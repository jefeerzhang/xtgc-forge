## 顺序铁律(不可颠倒)

1. **先翻译(反黑话)**:正文禁 GAP/Checkpoint/SESOI 等内部术语(delivery-spec §3.3)——humanizer 锁定技术术语,治不了黑话
2. **后润色(去 AI 味)**:本清单 / humanizer 处理文风

## 六大病灶自查

### A · 套话开头 / 过渡 / 收尾
- 段首:「随着……的发展」「近年来,……引起了广泛关注」「众所周知」「在……背景下」——删或换成具体场景
- 过渡:「综上所述」「总而言之」「由此可见」「鉴于此」——删;「综上所述」只在全文结尾且确实在总结时保留
- 收尾:「为……提供了新的思路」「对……具有重要意义」「未来值得进一步深入研究」——删,以事实/结论收尾

### B · 价值判断词饱和
- 「重要 / 关键 / 显著 / 核心」密度过高且无证据——换成具体证据或机理;「显著」只在统计意义用,其余换「明显」或具体描述

### C · 抽象主语代替施动者
- 「时代 / 科技 / 行业 / 社会 / 趋势」+ 动词——换成具体主体;理论综述段已有研究指出的抽象主语可保留(能落地即可)

### D · 名词化动词
- 「进行优化 / 做出判断 / 实现增长 / 采取措施 / 起到作用」→ 「优化 / 判断 / 增长 / 写具体动作 / 起作用」;方法论段「进行分析/检验」是规范,别动

### E · 排比三件套
- 「既是……也是……更是……」「理论意义、实践意义、方法论意义」——保留最有信息量的一句,或用编号/表格;「首先/其次/最后」只在 3 个以上真正独立并列论点时保留

### F · 假客观 / 元评论
- 「本研究试图探讨」→「本研究探讨」;「下面我们来看」→ 直接说
- 「诸多研究表明 / 大量研究证实 / 学界普遍认为」→ 换成 1-2 个具体引用

## 段落节奏

- 同段句长有变化(避免连续 5 句同长)
- 每段一个核心句,其余围绕它
- 段间用「上段结论 + 下段问题」承接,不用「首先/其次」搭骨架
- 结论段以数据/推断/局限收尾,不抒情

## 对照清单(润色后过一遍)

- [ ] 段首无「随着/近年来/众所周知/在……背景下」
- [ ] 无「鉴于此 / 基于此」空过渡
- [ ] 无「为……提供了新的思路 / 具有重要意义 / 具有参考价值」
- [ ] 无「未来值得进一步深入研究 / 有待后续验证」
- [ ] 无「进行/实现/做出/加以/给予 + 抽象名词」(方法论段除外)
- [ ] 无连续三个排比短句
- [ ] 无「诸多研究表明 / 学界普遍认为」(已换具体引用)
- [ ] 无元评论(「本研究试图探讨」「下面我们来看」)
- [ ] 最后一段以事实/数据/推断收尾,不以抒情收尾

## 事实红线(绝对不改)

数字、公式、统计量、引文、术语、样本量、日期——一字不改。去 AI 味只动文风,不动事实。
